# Анализ и бенчмарк Open-Source Web-читалок и инструментов двуязычного чтения (≥ 10 репозиториев)

Для создания цифрового ридера и автоматизированного пайплайна импорта книг был проведен глубокий анализ передовых репозиториев на GitHub в категориях: веб-читалки, параллельное (bilingual) чтение, аннотирование/карточки и AI-трансляторы книг.

## 2. Ключевые архитектурные инсайты для нашего проекта

1. **Двухуровневый парсинг PDF (Детерминированный + Агентный):**
   * *Уровень 1 (PyMuPDF / fitz):* Мгновенное извлечение векторного текста, оглавления (TOC bookmarks), рендеринг WebP-сканов страниц (100% бесплатно и без токенов).
   * *Уровень 2 (`agy cli`):* Академический богословский перевод, привязка сносок и структурирование в строгий JSON.
2. **Мобильная эргономика (Apple Books / Readest standard):**
   * Bottom Sheet вместо боковых ящиков на экранах смартфонов (< 640px).
   * Touch Swipe навигация.
   * Safe Areas (`env(safe-area-inset)`) и PWA-манифест.
3. **Telegram HTTPS и коммуникация:**
   * Telegram Bot Long Polling (`getUpdates`) — стандарт, не требующий входящих портов, внешних IP и сторонних SSL-сертификатов на хосте, так как бот выступает HTTPS-клиентом к Telegram API.
   * На случай необходимости Webhook-режима предусмотрен туннель Cloudflare Tunnel (`cloudflared`) с автоматической выдачей бесплатного SSL-сертификата.
