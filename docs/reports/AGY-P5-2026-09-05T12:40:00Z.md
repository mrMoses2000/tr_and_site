## 3. Scope

### Запрошено этапом
1. Изоляция данных через Data Envelope (`TranslationEnvelope`): системные инструкции отделены от содержимого блоков, исключая prompt injection.
2. Строгая схема вывода и 1:1 сопоставление ID входных и выходных блоков (`BlockMismatchError`).
3. Запрет тихого успеха при возврате исходного текста (`FalseFallbackError`).
4. Детерминированный кэш по хэшу пакета `compute_batch_hash` (`TranslationCache`) для экономии бюджета и повторных запусков.
5. Фиксация таймаутов как `SUBMISSION_UNKNOWN` с запретом слепых повторов.
6. Обработка `RateLimitError` с сохранением `retry_after`.
7. Никаких платных вызовов модели на этом этапе.

### Выполнено
- Создан пакет `ingestion_service/translation/`:
  - `models.py`: Pydantic модели `TranslationPolicy`, `TranslationBlock`, `TranslationEnvelope`, `BlockTranslationResult`, `BatchTranslationResponse`.
  - `cache.py`: транзакционный SQLite кэш `TranslationCache` и детерминированная функция хеширования `compute_batch_hash`.
  - `validator.py`: валидатор `TranslationValidator`, выбрасывающий `BlockMismatchError` при расхождении ID и `FalseFallbackError` при дублировании русского текста в качестве казахского перевода.
  - `adapter.py`: модуль `TranslationAdapter` и `build_translation_payload` с типизированной границей и обработкой таймаутов (`SubmissionUnknownError`) и лимитов (`RateLimitError`).
- Создан тестовый сьют `ingestion_service/tests/test_p5_translation.py` из 7 тестов, покрывающий все граничные случаи.

### Осознанно не выполнялось
- Подключение реального платного ключа Gemini/OpenAI (запрещено до отдельного согласования бюджета).
- Массовый запуск перевода всех книг (запланировано на этапы P13/P14).

## 7. Архитектурные решения

| Решение | Альтернативы | Почему выбрано | Положительное следствие | Отрицательное следствие |
|---|---|---|---|---|
| Изоляция в JSON data envelope | Склеивание строк в shell prompt | Предотвращает prompt injection из содержимого PDF | Безопасность выполнения | Требует строгой сериализации |
| Блокировка идентичного текста (`FalseFallbackError`) | Принятие исходного текста как перевода | Устраняет критический дефект, когда ошибка модели маскировалась под готовый перевод | В каталог никогда не попадет фиктивный перевод | Требует повторной попытки или ручного решения |
| Кэш `translation_cache` по хэшу | Повторный вызов API при каждом запуске | Экономия средств и предотвращение дублирующих платных вызовов | Нулевая стоимость повторной обработки | Хранение кэша в локальной SQLite |
