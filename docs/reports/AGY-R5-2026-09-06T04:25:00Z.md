## 1. Problem Addressed
In previous phases:
1. **Contract R1-09 Failure**: Reader converted short diagram fragments, abbreviations, and lone letters (`Сп`, `Т`, `славы`, `в похвалу`) into `<h2>` headings because of a simplistic heuristic (`para.en.length < 50 && !para.en.includes(".")`).
2. **Contract R1-10 Failure**: Reader ignored AST `blocks` array when present on a page, falling back to flat unstructured paragraphs and failing to render diagrams/figures (`FigureBlock`).
3. **Hardcoded Book Metadata**: Header and chapter breadcrumbs fell back to hardcoded Schreiner strings when switching or loading non-Schreiner books.

---

## 2. Implementation Changes

1. [`app/src/components/ReaderContent.tsx`](file:///home/moses/tr_and_site/app/src/components/ReaderContent.tsx):
   - Integrated `DocumentBlockRenderer`: If `page.blocks` is present and non-empty, `ReaderContent` renders the page using the AST block renderer, preserving `figure`, `heading`, `quotation`, `table`, `list`, and `footnote` blocks with source anchors and click handlers.
   - Replaced weak heading heuristic with `isHeadingParagraph`:
     - Requires start with uppercase letter or digit (`^[A-ZА-ЯЁ0-9]`).
     - Requires minimum length >= 4 and < 80 characters.
     - Disallows footnote citation markers (`[7]`, `^[1]`, superscripts) which indicate body prose.
     - Disallows internal sentence periods.
     - Disallows known diagram syntax tokens (`Сп`, `Т`, `Е`, `К`, `С`, `славы`, `в похвалу`).
     - Aligns `isAfterHeading` drop-cap evaluation to prevent spurious drop-caps after diagram labels.
2. [`app/src/components/ast/DocumentBlockRenderer.tsx`](file:///home/moses/tr_and_site/app/src/components/ast/DocumentBlockRenderer.tsx):
   - Enhanced `FigureBlock` rendering to handle both `InlineRun[]` and plain string captions gracefully without throwing exceptions.
3. [`app/src/domain/v2/types.ts`](file:///home/moses/tr_and_site/app/src/domain/v2/types.ts) & [`app/src/domain/types.ts`](file:///home/moses/tr_and_site/app/src/domain/types.ts):
   - Added `blocks?: DocumentBlock[]` to `PageData`.
   - Permitted `caption?: InlineRun[] | string` on `figure` block contract.
4. [`app/src/components/Header.tsx`](file:///home/moses/tr_and_site/app/src/components/Header.tsx):
   - Replaced hardcoded `"Reflections on NT Theology"` fallback with `{chapterTitle || bookTitle || "Чтение"}`.
