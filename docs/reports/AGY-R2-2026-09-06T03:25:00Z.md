## 1. Problem Addressed
In previous phases:
1. **Destructive dehyphenation**: Line-end dehyphenation used unanchored regexes replacing `\w+\x1e\w+` -> `\1\2`, mutating numerical ranges (`2.6\x1e11` -> `2.611`), compound adverbs (`Во\x1eвторых` -> `Вовторых`), and ordinals.
2. **Page 46 Intra-sentence Splitting**: PyMuPDF emitted 4 distinct text blocks on page 46 (bbox vertical gaps ~1.9-2.1 pt) around superscript footnote marker `[7]` and inline list items `(1)`, `(2)`, `(3)`. As a result, words were broken across block boundaries (`привле`/`кает`, `прилагатель`/`ные`, `разви`/`тие`).
3. **Multi-run Separator Disconnect**: InDesign exported soft hyphens (`\x1e`) as separate single-character spans or at the end of runs without newlines (`\n`), causing `_normalize_runs` to miss dehyphenation.

## 2. Implementation Changes
1. [`ingestion_service/ast/normalization.py`](file:///home/moses/tr_and_site/ingestion_service/ast/normalization.py):
   - Pattern 1: Preserves numeric/verse ranges with en-dash (`2.6–11`, `2–5`, `7–8`, `10–11`).
   - Pattern 2: Preserves ordinal suffixes (`60-е`, `3-я`).
   - Pattern 3: Cleans soft hyphens followed by space/tab (`[ \t]+`) without consuming newlines.
   - Pattern 4: Restores line-end dehyphenation across line breaks with lexicon check (`Во-вторых`, `две-три`).
   - Pattern 5: Preserves inline compound words with hyphens.
2. [`ingestion_service/ast/builder.py`](file:///home/moses/tr_and_site/ingestion_service/ast/builder.py):
   - Added `_should_merge_blocks` and `_merge_adjacent_blocks`: Merges adjacent text blocks when they reside in the same column, have line-spacing vertical gaps (<= 6.0 pt, or <= 12.0 pt for trailing hyphens), and exhibit syntactic continuation (trailing soft-hyphen/hyphen or non-terminal punctuation followed by lowercase start).
   - Added isolated separator span handling in `_normalize_runs`: Detects single-character separator spans (`\x1e`, `#`) between word parts and safely eliminates them with full audit provenance.
   - Updated `separator_pattern`: Now matches trailing `#`, `\x1e`, `-` with optional trailing newline.
3. [`ingestion_service/pdf_extractor.py`](file:///home/moses/tr_and_site/ingestion_service/pdf_extractor.py):
   - Replaced destructive unanchored dehyphenation with `normalize_text`.
4. [`ingestion_service/ast/validator.py`](file:///home/moses/tr_and_site/ingestion_service/ast/validator.py):
   - Added `validate_multiset_digits` (checking exact multiset digit preservation).
   - Added `validate_figures_presence` (verifying diagram extraction presence).
