## 3. Scope

### Запрошено этапом
```text
- Устранить монолитный eager bundle (ранее 6.5 MB из-за прямого импорта манифеста Осборна на 736 страниц).
- Реализовать легкий registry summary для мгновенного отображения каталога без загрузки текста книг.
- Page repository с загрузкой чанков по требованию (LazyPageRepository), кэшированием и типизированной ошибкой UnavailableChunkError.
- Search Engine V2:
  * Поиск всех повторных совпадений в одном абзаце (ранее indexOf находил только первое).
  * Таргетинг сносок с сохранением footnoteId.
  * Лимит результатов (maxResults) и отчёт об общем числе совпадений (totalMatches, truncated).
  * Дебаунс 200–250 мс и отмена (cancellation) устаревших in-flight запросов при быстром вводе.
```

### Выполнено
```text
1. Bundle Budget & Lazy Registry:
   - В app/src/data/library/libraryRegistry.ts монолитный eager glob заменен на легковесный статический registry summary (bookSummaries).
   - Манифесты книг вынесены в динамические чанки import.meta.glob('../books/*/manifest.json') без флага eager.
   - Размер продакшн-бандла Vite сократился с 6 527 kB до 682 kB (сокращение на 90%!), gzip с 1 067 kB до 156 kB.

2. Lazy Page Repository (app/src/domain/repository/pageRepository.ts):
   - LazyPageRepository с кэшированием в Map, дедупликацией in-flight промисов и prefetch соседних страниц.
   - Класс ошибки UnavailableChunkError для изоляции сетевых сбоев/отсутствующих страниц без падения UI.

3. Search Engine V2 (app/src/domain/search/searchEngineV2.ts):
   - Цикл поиска находит ВСЕ вхождения строки в абзаце/сноске со смещениями (offset) и контекстными сниппетами.
   - Поддержка таргетинга сносок (targetType: 'footnote', footnoteId).
   - Ограничение выдачи maxResults и метаданные truncated/totalMatches.
   - createDebouncedSearchWorker с отменой устаревших промисов при вводе нового символа.

4. Обновление UI поиска (app/src/components/SearchDialog.tsx):
   - Дебаунс 200 мс, лимит 50 результатов, отображение общего числа совпадений.
   - Динамическое отображение количества страниц книги вместо захардкоженного «22 страницам».
   - Индикация сносок (бейдж «Сноска N») и передача paragraphId для фокуса.
```

## 7. Архитектурные решения

| Решение | Альтернативы | Почему выбрано | Положительное следствие | Отрицательное следствие |
|---|---|---|---|---|
| Вынесение манифестов книг в динамические чанки Vite | Монолитная сборка всех книг в один JS-файл | Монолитный бандл весил 6.5 MB и блокировал загрузку главной страницы | Главный бандл уменьшен на 90% (до 682 kB raw / 156 kB gzip) | Первая загрузка книги требует асинхронного fetch чанка |
| Мягкая отмена устаревших поисковых запросов в worker | Запуск поиска на каждый onChange без отмены | При быстром вводе пользователя накапливались блокирующие main-thread задачи | Поиск не тормозит интерфейс ввода | Необходимость обработки rejected promise |
