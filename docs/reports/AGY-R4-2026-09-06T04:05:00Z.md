## 1. Objectives & Scope
Phase R4 integrates the AST V2 generation and fidelity validation pipeline into the core ingestion workflow:
1. **Authoritative AST Generation in Extractor**: Ensure `PDFExtractor.extract_page_structure` uses `DocumentAstBuilder` to generate structured `DocumentPage` ASTs with typed blocks (`heading`, `paragraph`, `figure`, `footnote`, `pageBreak`).
2. **Content-Aware Drawing Filter**: Implement coordinate-based filtering (`get_content_drawings`) to distinguish meaningful vector diagrams from margin crop marks (e.g. on pp. 46, 736) and footnote separation rules.
3. **Fidelity Validation in Ingestion**: Wire `FidelityValidator` directly into the page structure output, verifying both multiset digit preservation and figure presence.
4. **AST V2 Pipeline & Adapter Compatibility**:
   - Update `adapt_manifest_v1_to_v2` in `v2/contracts.py` to preserve existing `blocks` from the AST rather than falling back to synthesized paragraph blocks.
   - Update `DocumentBlock` model to support `caption`, `captionRuns`, and arbitrary extra fields safely.
5. **Python 3.14 Soft-Hyphen Handling**: Fix whitespace stripping bug where `\x1e.strip()` evaluated to `""` in Python 3.14, ensuring seamless paragraph continuations.
