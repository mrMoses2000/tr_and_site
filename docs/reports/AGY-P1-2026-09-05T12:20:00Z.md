## 3. Scope

### Запрошено этапом
1. Tests для `ManifestV1 -> V2`, stable block IDs, source anchors, capabilities и schema rejection.
2. Domain models, schemas и адаптеры в frontend (`app/src/domain/v2`) и backend (`ingestion_service/v2`).
3. Корректный вывод возможностей языков: книга с русским оригиналом (где `en == ru`) не должна объявлять английский язык доступным.
4. Полное сохранение работоспособности существующих тестов читалки (V1 manifest compatibility).

### Выполнено
- Создан модуль типов `app/src/domain/v2/types.ts` (`BookManifestV2`, `DocumentBlock`, `SourceAnchor`, `InlineRun`, `PageV2`, `TocNode`, `LanguageCode`).
- Создан модуль адаптера `app/src/domain/v2/adapter.ts`: функции `adaptManifestV1ToV2`, `validateManifestV2`, `isManifestV2`, детерминированное хеширование `computeCandidateHash`.
- Написан сьют тестов `app/src/tests/contracts_v2.test.ts` (6 тестов) с подтверждением падения в RED и перехода в GREEN.
- Создан backend пакет `ingestion_service/v2/contracts.py` на базе Pydantic V2 с валидацией схемы, защитой от инвертированного `pageRange`, детерминированными ID и проверкой языковых возможностей книги.
- Написан сьют тестов `ingestion_service/tests/test_v2_contracts.py` (3 теста) с подтверждением падения в RED и перехода в GREEN.
- Исправлен неиспользуемый импорт типа в тестах для чистого прохождения `npm --prefix app run build` (`tsc -b`).

## 7. Архитектурные решения

| Решение | Альтернативы | Почему выбрано | Положительное следствие | Отрицательное следствие |
|---|---|---|---|---|
| Двусторонний адаптер V1 -> V2 (TS и Python) | Полный единоразовый перенос читалки на V2 AST | Изолирует изменения, предотвращает поломку текущего UI читалки | Существующий ридер продолжает работать без изменений | Необходимость поддержки логики адаптера до полного перехода |
| Детерминированные Block ID (`blk-{slug}-p{page}-{idx}`) | Случайные UUID v4 | Идемпотентность, воспроизводимость цитат и закладок | Стабильные ссылки между версиями и аудиопотоками | Требует строгой нумерации блоков |
| Изоляция языковых capabilities книги | Объявлять все языки из глобального словаря | Устраняет критический дефект, когда русская книга выдавала псевдо-английский | Читалка никогда не предложит ложный перевод | Необходим анализ контента параграфов |
